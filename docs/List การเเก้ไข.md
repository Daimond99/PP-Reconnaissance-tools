# List การเเก้ไข

**1. ปรับแก้ไฟล์ Constraint (`.md`) สำหรับควบคุม AI Agent (ง่ายที่สุด)**

- ตรวจสอบและอัปเดตกฎในไฟล์ `.md` (เช่น `AGENTS.md`) ให้ครอบคลุม
- ใส่ลิสต์เครื่องมือที่อนุญาต (Whitelist 6 ตัว: Nmap, Masscan, Hydra, Ncrack, Ncat, Evil-WinRM)
- กำหนดคำสั่งกลุ่มเสี่ยงสูง (Critical Commands เช่น การทำ Brute-force / Probing) ว่าต้องสั่งให้ระบบหยุดรอรับการยืนยันจากมนุษย์ก่อนเสมอ

**2. ตรวจสอบและจัดการสิทธิ์ `sudo` ไม่ให้ฝังรหัสผ่าน (ง่าย)**

- ตรวจเช็กโค้ดส่วนเรียกคำสั่งสแกน/สคริปต์ ให้มั่นใจว่าไม่มีการ Hardcode หรือเขียนรหัสผ่าน Root ลงในไฟล์ Config หรือตัวแปรค้างไว้
- ปรับให้รับค่าผ่าน Interactive Prompt เป็นรายครั้ง และทำการเคลียร์ตัวแปรรหัสผ่านทิ้งทันทีหลังรันเสร็จ

**3. จัดการ Engine ของ AI ให้ใช้ OpenCode เป็นหลัก (ปานกลาง - ง่าย)**

- ปรับโค้ดส่วน AI Mode ให้ใช้ OpenCode API จัดการเรียกเครื่องมือตามบริบท
- ปิดหรือตัดส่วน Plugin ย่อยที่ไม่จำเป็นออก เพื่อลดความซ้ำซ้อนและทำให้การทำงานของ AI นิ่งขึ้น
  
**4. ปรับปรุง UI หน้า Wizard Console จาก Text-Menu เป็น GUI (ปานกลาง)**

- ยกเลิกหน้าต่างข้อความที่ให้ผู้ใช้พิมพ์ตัวเลขชอยส์ $1, 2, 3$ ใน Console
- เปลี่ยนเป็นใช้วิดเจ็ตของ PySide6 (เช่น QRadioButton, QCheckBox, ปุ่มกด Next / Back) ในการเลือก Step การสแกน
- ทำกล่อง Pop-up / Dialog ยืนยันคำสั่งและแสดงคำเตือนระดับความเสี่ยงก่อนสั่ง Execute
